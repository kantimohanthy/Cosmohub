# CosmoHub-Next Product Roadmap

### Phase 1: Interactive Prototype (Current)
- Demonstrate the two-layer architecture (Intelligence Core + Product SPA).
- Provide gamified entry points connected natively to intelligence endpoints.

### Phase 2: Backend Data Integration
- Replace `data/ecosystem.js` with a live graph database (e.g. Neo4j, Datomic).
- Implement Python-based data ingestion pipelines from CORDIS, Space-Track, and ESA open data.

### Phase 3: Identity & Provenance
- Allow users to authenticate.
- Track individual XP progression over time.
- Users can document Projects directly into the graph.

### Phase 4: Institutional Pilots
- Partner with universities to deploy learning modules.
- Map talent (Students/Researchers) directly to the Opportunity edges graph.
